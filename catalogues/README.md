# catalogues/

- `bw_features/`: catalogue of map features used on Brood War ladder maps (terrain, doodads, water/cliff pieces), with `features.json` and the generator `gen.py`.
- `wc3_scenes/`: 100 scene ideas for Warcraft III maps and missions (`WC3_Scene_Catalogue_100.md`, `scenes.json`), with unit/doodad IDs.
