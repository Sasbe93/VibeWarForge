# race_testmap – parallel lanes (parallel_lanes/lane_isolation)
- `gen_testmap.py --lanes N` (default 5, 1 = sequential) `--excl-reach R` (default 2000).
- `lanes.py` plans everything: which tests run alone, jobs (test + chained sub-tests; tests sharing a cmp key bundled), LPT queue, layout (2 rows), a static isolation check (arenas grown by max parallel reach must not overlap each other or the base; the build fails otherwise) and a runtime estimate.
- Runs alone: modes RESEARCH/GOLD/LUMBER/<race-specific modes>/BUILD/TRAIN/LEARN, specs 2,4-9 (time of day, revive, gold, mine, fog, upgrades), gold/lumber metrics, reach > excl-reach. Reason: the race pack supports only ONE owner player (XInit(Player(2))), so tech/resources/vision are shared by all lanes.
- Isolation at runtime: one enemy computer player per lane (Player 1, 3..11), enemies neutral to each other; single-test driver globals swapped per lane by the generated RT_Save/RT_Load (RT_Enter/RT_Leave, nesting-safe); arrays offset per lane (gLO/gLS/gLT/gLP); events dispatched to the lane by unit position (RT_LaneAt), cross-lane damage/casts are blocked and give CONTAMINATED.
- Selection tests share a mutex (gSelLane). Observer selection is enabled; units stay computer-owned (shared vision, no shared control).
- Chat: -lane N, -free (or arrow key), -next/-prev, -lanes, -skip N, -repeat N (queued as a dynamic job), -pause; ESC skips the followed lane.
- results.txt: `[m:ss] L<n> ...` lane column (`--` = none).
- Validate: pjass (built in), check_map_loadable --ref <known-good.w3x> (imports carried by default; `--no-imports` optional), check_w3x, check_timer_sleep.
- test_timing speed: tick RT_DT 0.1, RT_ANNOUNCE/RT_PAUSE 0.3, early stop (RT_EarlyOk, RT_OKTICKS=2 passing ticks, ≥RT_MINWIN after cast) for plain positive tests only; debuff tests wait ≤RT_DEBUFFWAIT; selection uses a short global lock gSelLock (RT_SELWAIT 0.2) instead of a job mutex, so SELECT/CSEL run in all lanes at once. gRTAge restarts at the cast. Cooldowns untouched (one cast per test).
- condition_test: mine-built buildings (ugol-like): RT_MineOrder (RT_Act worker, resources, exact mine XY, log accepted/start/finish), RT_MineWatch timeouts RT_BUILDSTART 12 s / RT_BUILDDONE 5 s; negative spec 13 (away from mine refused). Every wait has a timeout.
- real_clicks: selection tests: model file must exist (listfile), ussc>0, hit radius, no Aloc; without a real click -> WATCH; -repeat runs ask 'CLICK X NOW' and listen to EVENT_PLAYER_UNIT_SELECTED (outside the script lock) for proof.
- metrics: ORDEROK on unit casts = order accepted + SPELL_EFFECT (script-only effects); hint `taunt` re-arms E1/E2 for Atau (measure EMOVE); AHIDE also passes for a PASSIVE caster hidden from the enemy at the end of the window (v30). See docs/race-test-harness.md.
